## 실사 질감 수정

최근 추가한 삼성 외관·향남 외관·궁평항 횟집은 과한 파란 하늘, 건축 CG 같은 반사와 매끈한 표면, 노을 광고 조명을 줄이고 자연스러운 현장 촬영 질감으로 수정했습니다. 수산시장 이미지는 현재 사용 태그 및 갤러리에서 제외했습니다.

횟집은 [궁평항횟집 실제 실내 후기](https://mars97.tistory.com/566)의 두 실내 사진(`references/gungpyeong_restaurant_room_actual.png`, `references/gungpyeong_restaurant_room_wide_actual.png`)으로 공간 기준을 통일했습니다. 붉은 의자·흰 형광등·목재 벽·주름형 배기덕트·평범한 창문을 반영합니다. 이전의 커다란 항구 파노라마 창가는 현재 컷의 기준이 아닙니다. 사진은 현장 원본을 참고한 새 생성 이미지이며 실제 업소 기록 사진과 구별합니다.


콕핏 항법 화면은 창작 SF 소품입니다. 왼쪽 붉은 화성의 X와 오른쪽 아시아 중심 반쪽 지구·한반도를 구분합니다. 외계인은 기존 @alien_squad 4명뿐이며, 세 명의 전사가 녹색 티렉스 항법사를 질책합니다. HUD 이미지 자체에는 캐릭터를 넣지 않아 영상에서 반응과 손동작을 별도로 연출할 수 있습니다.


## 항법 HUD 현재 구도

왼쪽 붉은 화성에 X, 오른쪽 화면 가장자리에 절반만 보이는 큰 지구를 배치합니다. 아시아 중심 지구에서 중국·일본 사이의 한반도가 잘 보이게 합니다. 락온 지점에서 오른쪽으로 연결된 큰 AR 창에 ‘화성’ 두 글자만 크게 표시합니다. 창 배경은 반투명 검은색, 글자는 밝고 굵게 처리합니다. 중앙 여백의 목적지 글씨는 제거했습니다. 한반도 중서부, 서울 남서쪽 경기도 화성시 서해안에 작은 청록색 원형 십자 락온을 표시합니다. 목적지 글자와 함께 위치를 전달합니다.
