# 여성 히어로 윤식당 광고 — 장면 설계 및 제작 기준

2026-10-10 사용자 상세 설정 반영. 이전 남성 히어로 안을 대체하는 현행 기준. 9:16 실사 영화 톤. 90초를 편집 가안으로 제안하며 길이는 미확정.

## 캐릭터·공간
- 주인공: 30대 초반 여성, 남편과 아이 한 명과 가족 외식. 비행·초인적 힘·에너지 방출 능력. 식사복 그대로 전투하고 복귀. 실제 유명 배우나 특정 히어로 외형을 복제하지 않는다.
- 남편: 아내 맞은편, 창을 등짐. 아이: 테이블 측면, 제안 연령 5~7세, 성별 미확정.
- 여자는 창을 바라볼 수 있는 자리. 카메라는 어깨 뒤 사선에서 음식·창·바다를 함께 담는다. 실제 매장 사진 기준으로 배치하며 남편이 시선을 막지 않게 카메라 각도 조정.
- 괴수: 거대한 문어형 해양 외계인. 전투 중에는 위협적 실루엣, 의도는 쿠키까지 숨긴다. 촉수 수·무늬·눈 위치를 고정.
- 인간형 괴수: 정상 인간으로 변신하되 괴수와 연결되는 색·장신구를 유지.
- 부하 2명 가안: 인간형 몸, 해양 생물 느낌 얼굴, 비전투 연구·기술 담당 복장.
- 외계 공간: 고도로 발전한 문명의 높은 중앙 홀, 거대 포털을 위한 비어 있는 중앙부, 관측 회랑과 정교한 장치. 의식 공간처럼 신비롭되 기계 문명의 흔적을 유지.
- 포털 장치: 바닷속 이동 포털 생성기. 인간화 장치: 괴수의 작은 휴대 기계. 서로 다른 모양·색으로 구분.

## 편집 가안 90초
0–6: 실제 매장 입장, 가족을 뒤 사선으로 따라가 창가 식탁 공개.
6–16: 상차림. 45도 하이앵글의 짧은 아크 이동으로 한 상 공개, 반찬 인서트, 차돌·관자·백김치 접시와 굽는 장면. 실제 사진의 메뉴·식기·배치를 유지.
16–23: 삼합 첫 한입 직전. 여성 어깨 뒤 창밖에 먼 괴수 등장. 눈 리액션, 한입을 내려다보는 인서트.
23–27: 정부 재난상황실 한 컷. 감시 화면의 해상 이상현상, 담당자 '해상 거대 생명체 확인. 비상 대응 발령합니다.' 화면 문자는 후반 합성. 뉴스 장면 없음.
27–31: 여성 '꼭 지금이냐…' / 가족에게 '나 잠깐 화장실.' 가족은 의심하지 않음.
31–47: 비행 접근 → '돌아가. 나 지금 시간 없어.' → 괴수의 설명 못하는 당황 → 짧은 가격 → 촉수 하나를 잡아 회전 → 외해 투척 → 즉시 추격 잠수 → 수중 포털 확인 → 괴수를 포털 안으로 밀어넣음 → 지구 쪽 포털 생성기를 파괴. 장황한 대치나 괴수 반격 없음. 각 핵심 동작을 별도 쇼트로 생성해 빠르게 편집.
47–55: 수면 위 복귀, '아, 다 젖었네.' 에너지로 건조. 화장실 거울에서 머리·옷 정리. 착장은 전후 동일.
55–65: 가족이 눈치채지 못한 복귀. 남편이 아이 밥을 챙기는 행동이 앞뒤로 이어진다. 여성 삼합 한입 완주, 반찬 나눔, 바다와 식탁의 평온. 귀환 시간 관련 대사 없음.
65–67: 식사 장면에서 검정 페이드아웃 후 외계 홀로 페이드인.
67–82: 포털은 닫힌 외계 홀. 젖고 억울한 괴수가 작은 기계를 누르다 갑자기 인간형으로 정상 변신. '이제 돼? 하필 그때 고장 나서… 밥도 못 먹었잖아!' 윤식당 예약 화면 인서트. 기계를 바닥에 던져 파괴. 부하 '죄송합니다. 다음엔 이런 실수 없겠습니다.' 괴수 '예약부터 다시 잡아.' 인간형 유지.
82–90: 음식·전망 홍보 모션그래픽. 제안 문구 '히어로도, 괴수도. 목적지는 윤식당.' / '1++ 한우 · 차돌삼합 · 직접 만드는 반찬' / 네이버 검색창 '윤식당 차돌박이 해운대본점'. 브랜드 글자와 검색 UI는 편집 합성.

## 프롬프트 제작 준비
필수 인물 시트: 여성 식사복 정면·측면·후면·표정 및 젖은/건조 상태, 남편, 아이, 문어 괴수, 인간형 괴수, 연구 부하.
공간 시트: 실제 매장 외관/입구/창가 테이블/여성 OTS 시야/반대편 구도, 화장실 거울, 바다 수면·수중·포털, 정부 상황실, 외계 홀.
소품 시트: 실제 상차림과 식기·불판, 삼합 접시, 포털 생성기, 인간화 장치.
사진 확보 후 인물 시트 → 매장 공간과 테이블 배치 고정 → 음식·괴수·외계 공간 고정 → 쇼트별 시작 이미지 → 영상 프롬프트 순서.
한 쇼트에는 주요 행동 1개와 주 카메라 이동 1개. 액션 방향은 투척과 추격 사이 유지. 360도 이동을 모든 컷에 쓰지 않음. 음식 360도 회전 대신 제한된 아크 이동으로 재료 형태를 유지.
실제 테이블의 음식 상태: 처음은 준비·조리 → 외출은 완성 삼합을 앞접시에 둠 → 복귀는 같은 삼합과 배치 → 식사 중 변화. 남편·아이의 행동과 괴수 처리 시간을 교차하여 짧은 부재로 표현.

## 쿠키 연기 수정 (2026-10-10)
괴수는 인간형으로 변신한 후 기계를 던져 부수고 부하들의 사과를 듣는다. '예약부터 다시 잡아'라고 말한 뒤 돌아서 걸어가면서 맞은 얼굴을 손으로 만지고 '아야…' 한다. 분노 뒤에 통증과 억울함을 남긴다.

## 최신 시각 설정 (2026-10-11)
괴수 인간형은 정상 인간 외모, 짧은 은회색 머리와 비대칭 청록 의상. 피부·귀·눈에 외계 흔적 없음. 상황실 화면은 한반도 및 부산 쪽 빨간 경보. 포털은 수중과 외계 홀 2개 공간 참조만 사용한다. 작은 포털 생성 장치 소품 및 그것을 파괴하는 인서트는 제외하고, 히어로가 포털 자체를 힘으로 닫는 것으로 정리한다. 인간화 장치는 별개이며 유지.

입구로 들어서는 인물의 시선 기준: 바로 오른쪽에 카운터, 왼쪽에 바다가 보이는 창문과 창가 좌석. 가족은 입장 후 왼쪽 창가로 이동한다. 생성된 @store_wide는 분위기 참고용이며 정확한 평면도나 촬영 방향 기준으로 쓰지 않는다. 이후 장면에서는 이 입장 기준 좌우 배치를 우선한다.

## 괴수 발견 컷 좌석·카메라 정정

사용자 지정 테이블 사진 기준 왼쪽 긴 변에 여자, 오른쪽 긴 변에 남편과 딸. 카메라는 여자 뒤에서 사진보다 왼쪽 바다 방향으로 조금 돌린다. 가족을 창 앞 정면으로 나열하지 않는다. @hero_ots 수정본으로 교체, 음식은 임시 표현.

## 괴수 발견 컷 상차림·바다 방향 수정

카메라를 여자 뒤에서 더 왼쪽으로 이동하여 남편과 딸 뒤 창으로 동백섬 쪽 바다를 보게 한다. 괴수는 도시나 육지가 아닌 바다에 배치한다. 제공 상차림 사진 4장을 기준으로 차돌·관자·백김치·전, 다양한 반찬, 솥밥, 생선구이, 찌개를 반영했다. @hero_ots 동일 파일 교체.

## 발견 컷 최종 연출 수정

여자 어깨 바로 뒤의 타이트 오버숄더. 벽돌 기둥 제거. 남편과 딸은 앞쪽 오른편 식사 중. 문어 촉수는 총 8개로 제한하고 수면 위에는 일부만 보이게 한다. 동백섬 쪽으로 넘어오는 괴수를 여자가 발견하면 괴수로 빠른 크래시 줌, 얼굴·진행 방향에 도달해 짧게 홀드한다. 정지 이미지에는 줌 블러를 넣지 않는다. @hero_ots 동일 파일 교체.

## 제작 방식 최종 정정 — 행동 컷 사전 생성 금지

입장·착석·첫 한입·비행·전투·수중 이동·복귀·반전 행동 장면을 개별 정지 이미지로 미리 그리지 않는다. 배경 사진과 인물 시트 및 필요한 음식 참고 이미지를 영상 생성에 넣고 프롬프트로 인물 배치·행동·카메라를 지시한다. 이미 만든 @hero_ots는 기존 참고 컷으로 유지하며 새로운 행동 컷을 추가 생성하지 않는다. 추가 이미지 제작은 필요한 배경·인물·소품 참고자료 또는 사용자가 명시적으로 요청한 컷에 한한다.
