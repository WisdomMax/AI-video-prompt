# 실제 매장 사진 참고

## 입구 구성 참고 — 제작 사용 금지

사용자 제공 영상 캡처는 공간 구조를 관찰하기 위한 참고일 뿐이다. 저장했던 원본은 삭제했다. 제작용 이미지 태그로 등록하거나 원본을 영상에 삽입하지 않는다. 현재 생성 작업에도 사용하지 않는다. 추후 제작용 사진이나 별도 제작 지시를 받은 뒤 진행한다.

관찰한 구조: 실내 공용 복도, 짙은 석재 무늬 벽과 아래쪽 청록색 면, 빨간 유리문, 문 왼쪽 간판과 가로 조명, 검은 메뉴 안내대, 밝은 타일 바닥. 캡처 UI와 자막은 매장 구성에 포함하지 않는다.

## 음식 구성 참고 — 제작 사용 금지

2026-10-11 사용자 제공 음식 영상 캡처는 대화에서 구성 관찰만 한다. 파일 복사, 영상 삽입, 생성 이미지 참조, 음식 재생성에 사용하지 않는다. 사용자가 추후 제공할 더 좋은 음식 사진을 기다린다.

관찰 가능한 구성: 여러 작은 그릇에 담긴 반찬, 쌈채소, 불판의 고기·버섯·전, 생선구이, 솥밥, 찌개, 누룽지. 캡처 자막의 전복·생선명·등급 표기는 사진만으로 확정하지 않으며 최종 메뉴와 촬영 사진으로 확인한다.

## @store_exterior — 외관 재구성 이미지

사용자가 외관 사진들을 참고한 이미지 제작을 요청하여 생성. 원본을 그대로 사용하지 않고 유리 외벽과 2층 간판을 재구성한 9:16 시안. 파일: assets/store_exterior.png. 생성 도구: built-in image_gen. 프롬프트: prompts/asset_prompts.json. 실제 건물의 정확한 실측 복제는 아니므로 장면 연결 시 층고와 창 배치 확인 필요.

## @store_entrance — 입구 정면 재구성

사용자가 새 입구 캡처를 참고한 정면 이미지 생성을 요청하여 제작. 원본 영상 캡처 자체는 사용하지 않고 구조만 참고하여 9:16으로 재구성했다. 빨간 유리문, 왼쪽 입체 간판과 조명, 청록색 하부 벽, 메뉴 안내대 유지. 문 너머 내부는 상상한 부분이며 실제 내부 기준으로 사용하지 않는다. 파일: assets/store_entrance.png. built-in image_gen 사용. 프롬프트는 prompts/asset_prompts.json에 기록.

## @store_wide — 전체 내부 와이드

내부 통로와 창가 사진 두 장을 종합해 생성한 16:9 공간 재구성 시안. 왼쪽 바다 창, 중앙 통로, 오른쪽 금색 테두리 거울, 안쪽 카운터·냉장고 배치. 실제 공간 실측 복제가 아니며 좌석 수와 거리 등은 추정. assets/store_wide.png. built-in image_gen 사용. 최종 프롬프트는 prompts/asset_prompts.json.

### 창가 곡면 수정

사용자 설명에 따라 왼쪽 창가를 직선 벽이 아닌 바다 방향으로 완만하게 돌출되는 곡면 공간으로 수정했다. 평평한 유리 패널들의 방향이 곡선을 따라 점진적으로 꺾이고 창 하단과 천장 가장자리도 함께 휜다. @store_wide 동일 파일 교체, 이전 시안 별도 보관 없음.

### 입구 방향과 홀 폭 정정

사진은 홀 안쪽에서 빨간 입구문 쪽을 바라본 방향이다. 입구문은 카운터 옆 오른쪽에 있으며, 입장 시 왼쪽으로 넓게 펼쳐지는 홀이다. 길고 좁은 통로형 해석을 폐기하고 폭이 넓고 깊이가 짧은 공간으로 @store_wide 교체. 왼쪽 창가는 완만한 돌출 곡면 기준을 유지한다.

## 최종 공간 방향 기준 — 사용자 확정

입구로 들어서는 인물의 시선 기준: 바로 오른쪽에 카운터, 왼쪽에 바다가 보이는 창문과 창가 좌석. 가족은 입장 후 왼쪽 창가로 이동한다. 생성된 @store_wide는 분위기 참고용이며 정확한 평면도나 촬영 방향 기준으로 쓰지 않는다. 이후 장면에서는 이 입장 기준 좌우 배치를 우선한다.

## @meal_sides_ref — 돌솥밥·생선구이·찌개 실제 참고

사용자가 참고자료 저장을 허용한 원본. assets/meal_sides_ref.png. 검은 돌솥에 흰밥과 콩·채소 고명, 긴 타원형 밝은 접시의 노릇한 통생선구이, 검은 뚝배기의 붉은 찌개와 두부를 시각 기준으로 삼는다. 생선 종류와 찌개 메뉴명은 사진만으로 확정하지 않는다. 자동으로 영상에 삽입하지 않고 음식 재구성 참고로 사용한다.
