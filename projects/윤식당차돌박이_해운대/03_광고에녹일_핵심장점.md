# 윤식당 광고에 녹일 핵심 장점

정리일: 2026-10-10. 사용자 제공 매장 소개와 공개 리뷰의 정성적 비교. 전체 리뷰 통계나 경쟁 매장 전수 비교가 아니다. 블로그 협찬 여부를 모두 확인하지 못했으므로 표현의 반복을 고객 전체의 합의로 단정하지 않는다.

## 우선순위
1. 한우를 중심으로 직접 만드는 다양한 반찬·생선·솥밥·찌개까지 즐기는 풍성한 한 상. 매장은 20첩을 강조하고 공개 후기에도 반찬 및 식사 구성에 대한 만족이 나타난다. 광고의 가장 강한 사건 소재는 '고기를 기다리는데 이미 한 상이 계속 차려지는 상황'. 정확한 20첩 적용 메뉴는 확인 후 연출한다.
2. 차돌·관자·백김치 삼합. 매장 제공 기준. 고기의 고소함, 관자의 쫄깃함, 김치의 산뜻함을 서로 다른 세 힘의 결합으로 시각화할 수 있다. 리뷰·메뉴에는 묵은지 표기도 있어 실제 촬영 메뉴는 확인한다. 삼합 자체의 독점성은 주장하지 않는다.
3. 바다와 마린시티 풍경을 함께 즐기는 식사. 매장은 전 좌석 해운대뷰를 강조하며 후기에도 창가 풍경 만족이 나타난다. 장르 세계에서 실제 매장 창밖으로 전환되는 반전에 활용한다.
4. 직접 만드는 손맛. 매장 원칙과 반찬 맛에 대한 후기 평가를 구분한다. 후기만으로 기성품 미사용을 검증할 수는 없다. 로봇이 흉내내지 못하는 손맛, 전수하는 비급 등의 원인으로 활용한다.
5. 차돌에 생선구이·솥밥·찌개까지 이어지는 든든한 식사. 전복돌솥밥은 과거 및 공개 후기에서 긍정적으로 등장한다. 실제 적용 세트는 매장 확인 필요. '임무가 끝난 줄 알았는데 다음 음식이 등장'하는 전개에 적합하다.
6. 가족·데이트·모임에서 편안한 식사. 사용자 제공 시설 정보와 가족 외식 후기 근거. 일부 후기의 직원 구이 서비스는 항상 적용되는지 확인 전 핵심 약속으로 쓰지 않는다.

## 광고 원칙
- 메인 장점 하나와 보조 장점 한두 개를 선택한다.
- 장점이 사건의 원인 또는 해결책이 되게 한다. 음식 컷과 설명 자막을 마지막에 붙이는 방식으로 해결하지 않는다.
- 우주·무협·괴수 설정은 허구이되 삼합 재료, 실제 상차림, 매장 풍경은 실제 기준으로 보여준다.
- 식당 이름을 다른 브랜드로 바꿔도 똑같이 성립하면 차별점 반영이 부족하다.
- 1++는 매장의 강한 품질 약속이나 다른 한우집에도 있는 특징이다. 풍성한 한 상·삼합·풍경의 조합으로 윤식당다운 경험을 만든다.
- 20년 셰프 경력, 2대 계승은 서사를 보강하는 매장 제공 정보다. 검증되지 않은 창업 연혁이나 인물 이력은 만들지 않는다.
- '유일', '전국 최고', '모든 고객 만족' 등의 객관적 비교 주장은 근거 없음.

## 사례
- 오컬트: 접시가 놓일 때마다 봉인이 풀려 손님이 겁먹는다. 끝에 실제 윤식당의 풍성한 상을 공개하고 악령마저 착석한다. 전달: 풍성한 반찬과 가족처럼 대접하는 식사.
- 무협: 세 힘을 각각 쓰는 고수들은 실패하고 차돌·관자·백김치를 합친 순간 비급을 완성한다. 전달: 삼합의 조합, 1++ 한우.
- SF: 모든 음식을 복제하는 로봇이 반찬의 손맛을 재현하지 못해 오류가 난다. 직접 만드는 손의 장면 후 로봇이 손님으로 예약한다. 전달: 직접 만드는 반찬과 손맛.
